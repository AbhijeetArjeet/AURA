# 📱 YPDlp — Android YouTube Downloader & Player (Liquid Crystal Edition)

A modern Android application built with **Jetpack Compose**, **Material 3**, and **Liquid Crystal glassmorphism aesthetics** for downloading and playing YouTube videos and audio.

---

## ✨ Key Features

- 💎 **Liquid Crystal Glassmorphism UI** — iOS-inspired translucent frosted glass cards, glowing neon accents, and smooth fluid animations.
- 📁 **YouTube Playlist Downloader** — Automatically detect playlist URLs and download entire playlists in 1 tap.
- 🎬 **High-Quality Downloads (1080p, 720p, 4K & MP3)** — Connects with the YPDlp engine to merge and save high-resolution streams directly into your device's `Download/YPDlp` folder.
- 📂 **In-App Downloaded Library** — Browse all downloaded video and audio files with file sizes, formats, and dates.
- 🎵 **Background Audio/Video Playback** — Built-in floating glass mini-player and notification controls to listen to downloaded media with the screen off or while using other apps.
- 📲 **Universal Device Installation** — Universal signed APK configuration that installs cleanly on any Android device.
- 🔗 **Share & Open with Any Player** — Direct integration with Android `FileProvider` to share to WhatsApp/Telegram or open in VLC/MX Player.

---

## 🏗️ How to Build the APK

### One-Click Build
Double-click **`build_apk.bat`** or run:
```bash
./gradlew assembleDebug
```

The installable APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`
